# Metode i tehnike testiranja programske podrške - Antonio Zeko

Ovaj projekt predstavlja skup UI testova izrađenih za web aplikaciju The Internet.

Testovi pokrivaju različite tipove web elemenata i interakcija poput:
- Provjeru naslova stranice
- Rad s checkbox elementima
- Odabir vrijednosti iz dropdown liste
- Dinamičko dodavanje i uklanjanje elemenata
- Rad s JavaScript alert dijalozima

# Korišteni alati i tehnologije

- Programski jezik: Java
- Test framework: TestNG
- Automation alat: Selenium WebDriver
- Preglednih: Google Chrome
- Driver: ChromeDriver
- IDE: Inellij IDEA

# Načini korištenja
Korištenje @BeforeMethod i @AfterMethod anotacija za upravljanje životnim tijekom testova, implementacija eksplicitnih čekanja pomoću WebDriverWait, korištenje različitih lokatora poput By.id, By.name, By.xpath i dr. te verifikacija očekivanih rezultata pomoću Assert metoda
